# 支付宝 AI付个人收款 · 易支付插件

为 彩虹易支付 提供「支付宝 Agent支付（AI付）/ Vibe Pay 基础收款」通道，调用官方 `alipay.trade.page.pay`，支持**个人支付宝账号**收款。

目前测试仅支持新版彩虹易支付！！！！！！因为问用的新版，旧版自测！


> 本项目是第三方插件，非支付宝官方项目；接口能力与开通规则以 [支付宝 Agent 支付文档](https://aipay.alipay.com/docs/overview.html) 为准。

## 特性

- 对接支付宝 AI付「AI网页应用收款」，产品码 `FAST_INSTANT_TRADE_PAY`
- 个人支付宝账号即可收款，无需企业资质
- 支持扫码支付、收银台登录支付
- 完整回调验签：校验 `app_id`、订单号、金额后自动入账
- 支持订单查询、退款、关闭
- 支持 RSA2 密钥 / RSA2 证书两种加签方式
- 支持正式与沙箱环境，可先用 0.01 元跑通全链路再上线





## 安装

1. 下载本仓库，将 `alipayai` 整个目录放入易支付系统的 `plugins/payment/` 下
2. 登录易支付后台 → 支付插件，确认列表中出现「支付宝AI付个人收款」
3. 进入「支付通道 → 添加通道」，插件选择「支付宝AI付个人收款」

## 配置说明

| 配置项 | 必填 | 说明 |
| --- | --- | --- |
| 接口加签方式 | 是 | RSA2 密钥或 RSA2 证书 |
| 应用APPID | 是 | AI付应用详情页中的 APPID |
| 应用私钥 | 是 | 开放平台「接口加签」生成的应用私钥 |
| 支付宝公钥 | 密钥模式必填 | 开放平台提供的支付宝公钥，填错会导致无法验签 |
| 应用公钥证书 | 证书模式必填 | `appCertPublicKey_*.crt` |
| 支付宝公钥证书 | 证书模式必填 | `alipayCertPublicKey_RSA2.crt` |
| 支付宝根证书 | 证书模式必填 | `alipayRootCert.crt` |
| 收款支付宝UID | 个人收款必填 | 本人 2088 开头的 16 位 UID |
| 支付宝网关 | 是 | 正式 `https://openapi.alipay.com/gateway.do`；沙箱 `https://openapi-sandbox.dl.alipaydev.com/gateway.do` |

## 开通流程

1. 打开 [一站式接入](https://aipay.alipay.com/open-flow/products)，使用本人支付宝登录
2. 选择 **Vibe Pay → 基础收款能力 → AI网页应用收款（网页）**
3. 按页面填写个人主体、经营类目、应用名称与网站地址，提交签约
4. 审核通过后，在控制台「产品管理」中获取 APPID 与密钥
5. 将参数填入上方通道配置

> 「智能收款套件（即刻收）」目前主要面向合作平台/白名单，个人收款请走「基础收款能力」。

## 沙箱测试

1. 网关改为 `https://openapi-sandbox.dl.alipaydev.com/gateway.do`
2. APPID、应用私钥、支付宝公钥换成沙箱应用的值
3. 下载「支付宝沙箱版 APP」，使用开通页提供的买家账号登录
4. 在易支付发起一笔 0.01 元订单，扫码完成支付
5. 确认后台订单状态变为已支付、异步通知正常接收

## 正式上线

1. 将网关换回 `https://openapi.alipay.com/gateway.do`
2. 全部参数替换为线上应用的值
3. 确认站点域名公网可访问（异步通知由系统自动生成）
4. 真实支付一笔小额订单验证，再测试退款

## 支付流程

```
用户下单 → 插件创建订单 → alipay.trade.page.pay 生成支付链接
        → 展示二维码 / 跳转支付宝收银台
        → 用户支付 → 支付宝异步通知 notify
        → 验签 + 校验金额 → 订单入账 → 返回 success
```

## 常用接口

| 方法 | 用途 |
| --- | --- |
| `submit` / `mapi` | 网页 / API 下单 |
| `qrcode` | 生成二维码，支付宝内直接跳转 |
| `pagepay` | 直接跳转支付宝收银台 |
| `notify` / `return` | 异步 / 同步回调处理 |
| `query` | 主动查询订单 |
| `refund` | 原路退款 |
| `close` | 关闭未支付订单 |

## 常见问题

**支付成功但订单未入账**
检查支付宝公钥是否填对，以及站点异步通知地址能否被公网访问；可在后台手动补单或调用查询接口。

**提示验签失败**
密钥模式请确认使用的是「支付宝公钥」而不是「应用公钥」；证书模式请确认三张证书均上传正确。

**个人账号能收款吗**
可以。签约「AI网页应用收款」后填写本人 2088 UID 即可，资金直接进入该支付宝账户。

**沙箱能收到真实资金吗**
不能。沙箱全部为模拟交易，不会产生真实扣款。
